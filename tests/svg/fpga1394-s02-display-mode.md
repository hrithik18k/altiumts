# S02 before and after

Both SVGs render the complete, checksum-pinned `fpga1394-s02.SchDoc`, including
the component wiring. Neither image is a screenshot or a manually drawn symbol.

- `__snapshots__/fpga1394-s02-display-mode-before.snap.svg` is the unmodified
  snapshot generated by the reproduction test in commit `3758c9f`, before the
  renderer fix. U1D uses the wrong display mode and shows 88 pins.
- `__snapshots__/fpga1394-s02-display-mode-after.snap.svg` is generated and
  checked by the current test. U1D uses the selected display mode and shows
  38 pins. Shared designator and value records remain visible.

The before image is historical review evidence, not an expected output for the
fixed renderer. To reproduce it, run the reproduction test at `3758c9f` after
`bun run download-references`. To update the after image on this branch, run:

```sh
bun test tests/svg/fpga1394-s02-display-mode.test.ts --update-snapshots
```

Both files appear as **Added** in PR #100 because neither exists on its base
branch. This exposes both versions in Files changed; it does not turn two added
files into GitHub's single-file swipe diff.
